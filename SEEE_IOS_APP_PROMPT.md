# Промпт для создания iOS-приложения Seee

Скопируй весь текст ниже и загрузи в нейросеть, которая создаёт приложения для iPhone.

---

## Общее описание продукта

**Seee** — мобильное приложение для психологической самопомощи и работы с убеждениями через структурированный диалог с ИИ. Пользователь описывает ситуацию или мысль, а приложение ведёт его по шагам к осознанию эмоции, ограничивающей мысли и альтернативных взглядов. Результаты можно сохранять в «нейрокарту», вести журнал, проходить тест в Telegram-боте и привязывать аккаунт к Telegram.

**Целевая аудитория:** русскоязычные пользователи, интересующиеся саморазвитием, снижением тревоги, проработкой убеждений в сферах: отношения, деньги, здоровье, секс, самооценка, работа, выгорание, семья, цели.

**Тон приложения:** тёплый, поддерживающий, без назиданий. Интерфейс — простой, как чат; можно отвечать коротко или развёрнуто.

---

## Регистрация и авторизация

- **Регистрация:** email, пароль, имя (опционально). Поддержка реферального кода (ref) из ссылки.
- **Вход:** email + пароль.
- **Восстановление пароля:** запрос ссылки на email, переход по ссылке, ввод нового пароля.
- **Подписка:** доступ к основному функционалу (сессии, нейрокарта, журнал, чаты) только при активной подписке. Проверка подписки при входе; при отсутствии — редирект на экран оплаты.
- **Привязка Telegram:** в личном кабинете пользователь может сгенерировать ссылку для привязки аккаунта к Telegram-боту Seee (тест личности, карточки из теста в приложении).

---

## Главный поток после входа

1. **Точка входа (Entry Gate):**  
   - Если у пользователя ещё нет ни одной сессии и он не проходил онбординг — показать короткий онбординг (что такое Seee, как работает разбор).  
   - Если сессии уже есть или онбординг пройден — сразу переход в «Галерею сессий».

2. **Проверка подписки:**  
   Если включена обязательная подписка и у пользователя нет активной — показать экран «Оформите подписку» с виджетом оплаты (Lava или аналог) и кнопкой «Я оформил подписку» для обновления статуса.

## Сессии (основной функционал)

**Сессия** — один «разбор» темы: пользователь и ИИ обмениваются сообщениями по структурированному пайплайну.

### Пайплайн из 9 шагов (логика бэкенда)

1. **PROBLEM** — описание проблемы/ситуации.  
2. **EMOTION** — какая эмоция возникает.  
3. **THOUGHT** — мысль, которая порождает эмоцию.  
4. **WHY** — откуда/почему возникла эта мысль.  
5. **IDEAS** — альтернативные идеи от ИИ.  
6. **FOUNDER** — кто/что «основатель» идеи (внутренний голос, родитель и т.д.).  
7. **PURPOSE** — цель этого «основателя».  
8. **CONSEQUENCES** — эмоциональные последствия принятия новой идеи.  
9. **CONCLUSION** — итоговый вывод пользователя.

На каждом шаге пользователь вводит текст (или выбирает вариант, если ИИ предлагает варианты). ИИ задаёт вопросы и даёт следующий шаг. Состояние пайплайна сохраняется на сервере; можно закрыть приложение и вернуться к сессии позже.

### Экран сессии (чат)

- Список сообщений: пользователь справа, ассистент слева (или по гайдлайнам iOS).
- Ввод текста внизу (поле + кнопка отправить).
- Индикатор «ИИ печатает» при ожидании ответа.
- При завершении пайплайна — возможность «Добавить в нейрокарту» и/или скачать документ сессии (если API отдаёт файл).

### Галерея сессий

- Список сессий пользователя: заголовок (или первые слова), дата. Сортировка по дате (новые сверху или снизу — на твой выбор).
- По тапу — переход в чат сессии.
- Создание новой сессии: кнопка «Новая сессия» или «Новый разбор»; при первом сообщении создаётся сессия на бэкенде и открывается чат.
- Фильтр/поиск по сессиям (опционально).

### Рекомендуемые карточки (из Telegram-теста)

- Если аккаунт привязан к Telegram и пользователь прошёл тест — показывать блок «Рекомендовано вам» с карточками (темы для разбора из теста). По тапу — создание новой сессии с этой темой или переход в чат с предзаполненным контекстом.

## Нейрокарта

- Визуализация сохранённых убеждений/мыслей по сессиям (дерево или карта узлов). Узел = тема/мысль; можно раскрывать и смотреть связь с сессией.
- Данные приходят с API (event map / root beliefs / иерархия концептов). Если API отдаёт граф — отобразить граф; если список — список с группировкой.
- Кнопка «Добавить в нейрокарту» в завершённой сессии отправляет на бэкенд запрос и обновляет нейрокарту.

---

## Журнал

- Записи пользователя по датам (если бэкенд отдаёт journal entries). Просмотр, добавление коротких записей. Опционально привязка записей к сессиям.

---

## Чаты (People)

- Список чатов с другими пользователями (друзья). Дружба: запрос/принятие. В чате — обмен сообщениями в реальном времени (WebSocket или long polling). Режимы чата (обычный/«объясни мне») могут быть из конфига бэкенда.
- Уведомления о новых сообщениях (push).

---

## Личный кабинет

- **Профиль:** имя, email, аватар (если есть), язык (ru/en).
- **Разделы:** быстрые ссылки на Галерею сессий, Нейрокарту, Журнал, Чаты.
- **Безопасность:** смена пароля, привязка/отвязка Telegram.
- **Обратная связь:** форма отправки обратной связи в поддержку.
- **Реферальная система:** персональная ссылка, счётчик приглашённых, бонусы (если есть в API).
- **Моя обратная связь:** список тикетов/обращений и их статус.

---

## Оплата подписки

- Публичная страница «Оплата подписки»: заголовок, краткое описание, виджет оплаты (Lava или другой), кнопка «Войти» для уже залогиненных. Без кнопки «Уже оплатили? Перейти к регистрации» на этом экране.
- После успешной оплаты платёжная система редиректит на страницу успеха. На ней — сообщение «Оплата прошла успешно» и одна кнопка «Перейти к регистрации» (и опционально «Войти»). Только на этом экране показывать кнопку перехода к регистрации.

---

## Публичные экраны (без авторизации)

- **Лендинг:** описание Seee, преимущества (быстро, удобно, глубоко, интересно), домены (деньги, отношения, здоровье и т.д.), CTA «Оформить подписку» / «Начать».
- **Вход, регистрация, восстановление пароля.**
- **Оплата подписки** (виджет + вход).
- **Успешная оплата** — только кнопка «Перейти к регистрации» и «Войти».
- **Юридические страницы:** Оферта, Персональные данные, Возвраты (можно вебвью или статичный текст).

## API и технические требования

- **Backend:** REST API (JWT в заголовке Authorization). Базовый URL настраивается (production/staging).
- **Ключевые эндпоинты (ориентир):**  
  - `POST /api/v1/auth/register`, `POST /api/v1/auth/login`, refresh token, forgot-password, reset-password.  
  - `GET/POST /api/v1/sessions` — список сессий, создание.  
  - `POST /api/v1/sessions/:id/messages` — отправить сообщение в сессию; ответ — ответ ИИ (или стриминг, если поддерживается).  
  - `GET /api/v1/sessions/:id` — детали сессии и сообщения.  
  - `POST /api/v1/sessions/:id/add-to-map` — добавить результат в нейрокарту.  
  - `GET /api/v1/event-map` или аналог — данные нейрокарты.  
  - `GET /api/v1/auth/subscription` — статус подписки.  
  - Чаты: друзья, чаты, сообщения (конкретные пути уточняются по API).
- **WebSocket (опционально):** для чатов и, если есть, для стриминга ответов ИИ в сессиях. Подключение с JWT в auth.
- **Хранение:** JWT (access + refresh) в безопасном хранилище (Keychain). При истечении access — обновление через refresh; при ошибке 401 — выход в логин.

## Дизайн и UX

- Светлая и тёмная тема.
- Шрифты и отступы — удобные для чтения; крупные зоны нажатия для кнопок.
- Онбординг — короткий, без перегруза; возможность пропустить после первого раза.
- Уведомления: разрешение запрашивать только после объяснения (новые сообщения в чатах, напоминания — если есть в продукте).

---

## Что должно получиться

Нативное iOS-приложение (Swift/SwiftUI или по возможностям нейросети), в котором пользователь может: зарегистрироваться и войти; оформить подписку; проходить пошаговый разбор с ИИ в сессиях; просматривать галерею сессий и открывать чат сессии; добавлять результаты в нейрокарту и просматривать нейрокарту; вести журнал; общаться в чатах с друзьями; управлять профилем, паролем и привязкой Telegram в личном кабинете. После оплаты кнопка «Перейти к регистрации» доступна только на экране успешной оплаты, а не на экране оплаты подписки.
