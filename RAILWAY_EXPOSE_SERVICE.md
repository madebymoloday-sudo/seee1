# 🔗 Подробная инструкция: Как получить ссылку на сайт в Railway

## ✅ Шаг 1: Вы уже выполнили
- ✅ Создали проект на Railway
- ✅ Сервис `seee1` задеплоен и работает

## 🎯 Шаг 2: Сделать сервис публичным (получить URL)

### Вариант A: Через вкладку "Settings" (Рекомендуется)

1. **Откройте вкладку "Settings"**
   - В верхней части страницы сервиса `seee1` вы увидите вкладки: "Deployments", "Variables", "Metrics", "Settings"
   - Нажмите на вкладку **"Settings"**

2. **Найдите раздел "Networking"**
   - Прокрутите страницу Settings вниз
   - Найдите раздел **"Networking"** или **"Public Networking"**

3. **Сгенерируйте домен**
   - В разделе Networking вы увидите опцию **"Generate Domain"** или **"Public Domain"**
   - Нажмите кнопку **"Generate Domain"** или переключите переключатель **"Public"** в положение **"ON"**

4. **Скопируйте URL**
   - После генерации домена появится URL вида: `https://seee1-production-xxxxx.up.railway.app`
   - Скопируйте этот URL - это и есть ссылка на ваш сайт!

### Вариант B: Через контекстное меню

1. **Откройте контекстное меню сервиса**
   - В левой панели найдите карточку сервиса `seee1`
   - Нажмите на три точки (⋮) или правой кнопкой мыши на сервис
   - Выберите **"View Settings"** или **"Config"**

2. **Перейдите в Networking**
   - В открывшемся окне найдите раздел **"Networking"**
   - Включите **"Public Domain"** или нажмите **"Generate Domain"**

## 🏗️ Шаг 3: Настройка двух сервисов (Backend и Frontend)

**Важно**: Сейчас у вас развернут только один сервис. Для полноценной работы приложения нужно два сервиса:

### 3.1. Переименование текущего сервиса в Backend

1. **Откройте настройки сервиса `seee1`**
   - Нажмите на сервис в левой панели
   - Перейдите в **"Settings"**

2. **Измените имя сервиса**
   - Найдите поле **"Service Name"** или **"Name"**
   - Измените имя с `seee1` на `backend`
   - Сохраните изменения

3. **Проверьте Root Directory**
   - В настройках найдите **"Root Directory"** или **"Source"**
   - Убедитесь, что указано: `back`
   - Если не указано, установите: `back`

### 3.2. Создание Frontend сервиса

1. **Создайте новый сервис**
   - В левой панели проекта нажмите кнопку **"New"** или **"+"**
   - Выберите **"GitHub Repo"** или **"Service"**

2. **Выберите репозиторий**
   - Выберите репозиторий `madebymoloday-sudo/seee1`
   - Railway начнет сканировать проект

3. **Настройте сервис**
   - **Service Name**: `frontend`
   - **Root Directory**: `front` ⚠️ **ОЧЕНЬ ВАЖНО!**
   - **Build Command**: (оставьте пустым)
   - **Start Command**: (оставьте пустым)

4. **Сохраните и дождитесь деплоя**
   - Railway автоматически начнет сборку и деплой Frontend
   - Дождитесь завершения (зеленый индикатор "Deployment successful")

## 🔧 Шаг 4: Настройка переменных окружения

### 4.1. Переменные для Backend сервиса

1. **Откройте Backend сервис** → вкладка **"Variables"**

2. **Добавьте следующие переменные:**

   Нажмите кнопку **"New Variable"** и добавьте по одной:

   ```
   NODE_ENV = production
   ```
   
   ```
   PORT = 3000
   ```
   
   ```
   DATABASE_URL = ${{Postgres.DATABASE_URL}}
   ```
   *(Если у вас есть PostgreSQL сервис, Railway автоматически подставит значение)*
   
   ```
   JWT_SECRET = [сгенерируйте случайную строку минимум 32 символа]
   ```
   *Для генерации используйте: `openssl rand -base64 32` в терминале*
   
   ```
   JWT_EXPIRES_IN = 15m
   ```
   
   ```
   JWT_REFRESH_SECRET = [сгенерируйте другую случайную строку минимум 32 символа]
   ```
   
   ```
   JWT_REFRESH_EXPIRES_IN = 7d
   ```
   
   ```
   FRONTEND_URL = ${{Frontend.RAILWAY_PUBLIC_DOMAIN}}
   ```
   *(Это автоматически подставится после создания Frontend сервиса)*
   
   ```
   OPENAI_API_KEY = [ваш OpenAI API ключ]
   ```

### 4.2. Переменные для Frontend сервиса

1. **Откройте Frontend сервис** → вкладка **"Variables"**

2. **Добавьте следующие переменные:**

   ```
   API_URL = ${{Backend.RAILWAY_PUBLIC_DOMAIN}}
   ```
   *(Railway автоматически подставит URL Backend сервиса)*
   
   ```
   VITE_API_URL = ${{Backend.RAILWAY_PUBLIC_DOMAIN}}/api/v1
   ```
   
   ```
   VITE_SOCKET_URL = ${{Backend.RAILWAY_PUBLIC_DOMAIN}}
   ```

## 🗄️ Шаг 5: Добавление PostgreSQL базы данных (если еще не добавлена)

1. **Создайте базу данных**
   - В левой панели проекта нажмите **"New"** → **"Database"** → **"Add PostgreSQL"**
   - Railway автоматически создаст базу данных

2. **Проверьте переменную DATABASE_URL**
   - Откройте Backend сервис → **"Variables"**
   - Убедитесь, что переменная `DATABASE_URL` установлена в `${{Postgres.DATABASE_URL}}`
   - Если нет, добавьте ее вручную

---

## 🔗 Шаг 6: Получение финальной ссылки на сайт

1. **Откройте Frontend сервис**
   - В левой панели нажмите на сервис `frontend`

2. **Перейдите в Settings → Networking**
   - Нажмите вкладку **"Settings"**
   - Найдите раздел **"Networking"**

3. **Сгенерируйте публичный домен**
   - Нажмите **"Generate Domain"** или включите переключатель **"Public"**
   - Появится URL вида: `https://frontend-production-xxxxx.up.railway.app`

4. **Скопируйте URL**
   - Это и есть финальная ссылка на ваш сайт! 🎉

---

## ✅ Шаг 7: Проверка работы

1. **Откройте URL Frontend в браузере**
   - Скопированный URL должен открыть ваше приложение

2. **Проверьте логи (если что-то не работает)**
   - Backend: Откройте сервис → **"Deployments"** → выберите последний деплой → **"View Logs"**
   - Frontend: Откройте сервис → **"Deployments"** → выберите последний деплой → **"View Logs"**

3. **Проверьте статус сервисов**
   - Оба сервиса должны иметь зеленый индикатор "Deployment successful"
   - Оба сервиса должны быть "Exposed" (публичными)

## 🐛 Решение проблем

### Проблема: "Unexposed service"
**Решение**: Выполните Шаг 2 (сделать сервис публичным)

### Проблема: Frontend не подключается к Backend
**Решение**: 
- Проверьте, что в Frontend переменных `API_URL` указан правильный Backend URL
- Убедитесь, что Backend сервис публичный (Exposed)
- Проверьте логи Backend на наличие ошибок CORS

### Проблема: Backend не запускается
**Решение**:
- Проверьте все переменные окружения (особенно `DATABASE_URL`, `JWT_SECRET`)
- Проверьте логи деплоя
- Убедитесь, что `Root Directory` установлен в `back`

### Проблема: База данных не подключается
**Решение**:
- Убедитесь, что PostgreSQL сервис создан
- Проверьте, что `DATABASE_URL` в Backend установлен в `${{Postgres.DATABASE_URL}}`
- Проверьте логи Backend на наличие ошибок подключения
